## Что делаем

В университете теперь есть люди двух видов — студенты и преподаватели. Университет ведёт их в одном журнале и работает с людьми, не разбирая, кто перед ним.

### Люди

Студент и преподаватель — наследники общего типа. Сам общий тип существует только как основа: его объект создать нельзя. В журнале лежат только конкретные люди — студенты и преподаватели.

- **студент** — номер, имя и зачётка с оценками. Показывает свой номер, имя, оценки и средний балл. Средний балл — дробное число; если оценок нет, он равен нулю. Ставить себе оценки студент не может.
- **преподаватель** — номер, имя и предмет, который он ведёт. Показывает свой номер, имя и предмет.

При печати у каждого человека видно, кто он и его подробности: у студента — оценки и средний балл, у преподавателя — предмет. Печать общая: все люди выводятся одним проходом по журналу, в порядке добавления, вперемешку. У каждого вида своя строка сведений.

### Журнал

Университет хранит один журнал всех людей — и студентов, и преподавателей — в порядке добавления. Номер человеку выдаёт университет, по порядку: 1, 2, 3, … Номера общие для обоих видов.

Университет умеет:

- зачислить студента по имени — без оценок;
- принять преподавателя по имени и предмету;
- найти человека по номеру;
- найти человека по имени;
- выдать всех людей в порядке добавления.

Поиск по имени находит и студента, и преподавателя.

### Оценки

Зачётка заводится студенту при зачислении. Хранит её университет и находит по номеру студента.

- поставить оценку по номеру — оценка от 2 до 5 записывается в зачётку студента; оценка вне диапазона — отказ;
- вернуть средний балл по номеру;
- если зачётки с таким номером нет — отказ.

Зачётка играет две роли: университет в неё пишет, студент — только читает. Чтение оформи отдельным интерфейсом `GradeView` (его в заготовке нет — создай сам): в нём те же два метода, что у зачётки, — средний балл и текст оценок. Зачётка реализует этот интерфейс, а студент работает с зачёткой только через него — поэтому поставить себе оценку не может.

Отказ оформляется исключением с понятным сообщением. Преподавателю оценку поставить нельзя: у него нет зачётки, поэтому попытка оценить его — отказ.

### Сценарий

Сценарий выполняется без меню и без ввода с клавиатуры.

1. Создай университет.
2. Зачисли Анну, прими на работу Виктора с предметом «история», зачисли Бориса — именно в таком порядке.
3. Поставь Анне оценки 4, 5 и 3.
4. Напечатай всех одним проходом: Анна, Виктор, Борис. У Анны — оценки и средний балл 4.0, у Бориса — оценок нет, у Виктора — предмет «история».
5. Попробуй поставить Виктору оценку — перехвати отказ и напечатай сообщение.
6. Найди Виктора по имени. Найди человека с именем «Иван» — перехвати отказ и напечатай сообщение.
7. Напечатай средний балл Анны.

## Сдача работы

После выполнения работы выполняется коммит + пуш + Pull Request в `main`.

### Как открыть Pull Request

1. Открой страницу своего репозитория на GitHub и обнови её. Сверху появится жёлтая плашка
   **Compare & pull request** — нажми её.
2. Проверь направление слияния: **base: `main`**, **compare: `task-4`**.
3. В поле **Title** напиши, например, `Практика 4: студенты и преподаватели`.
4. В описании PR добавь **скриншот выполнения класса `Main`** — окно Run целиком, чтобы были
   видны сценарий, оба вида людей и отказы.
5. Нажми **Create pull request**.
